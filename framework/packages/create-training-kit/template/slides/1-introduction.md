# How this deck is made

- One file per chapter in `slides/`, numbered: `1-introduction.md`, `2-first-steps.md`, …
- The number orders the deck — `10-…` comes after `9-…`
- `_3-draft.md` is turned off: kept on disk, left out of the deck
- `npm run list` shows what is picked up, and what is not
