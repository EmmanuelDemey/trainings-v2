# Training objectives

By the end of this training, you will be able to:

- Understand what is at stake with digital accessibility
- Know the standards and regulations (WCAG 2.2, RGAA 4.1)
- Build accessible interfaces
- Use ARIA correctly
- Test the accessibility of your applications
- Audit and fix accessibility issues

# Training methodology

## Teaching approach

- **Theory**: concepts and standards
- **Demos**: concrete examples
- **Practice**: hands-on exercises
- **Audit**: analysis of real-world cases
- **Q&A**: throughout the training

# Technical environment

## Prerequisites for the workshops

- A modern browser (Chrome, Firefox, Edge, Safari)
- A code editor (VS Code recommended)
- Node.js installed (for the local server and the Playwright tests)
- Recommended extensions:
  - [axe DevTools](https://www.deque.com/axe/devtools/) - Chrome, Firefox, Edge
  - [WAVE Evaluation Tool](https://wave.webaim.org/extension/) - Chrome, Firefox
  - [Accessibility Insights](https://accessibilityinsights.io/) - Chrome, Edge
