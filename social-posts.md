## LinkedIn (EN)

🎓 **Building a training shouldn't mean maintaining five different tools.**

For years, every course I gave came with the same chores: keeping the slides, the workshop instructions, the PDFs, the starter projects and the solutions in sync. So I built a tool that does it for me, and I'm making it open source:

**training-kit** turns two folders of numbered Markdown files and code into a complete training:

✅ a slide deck (Slidev)
✅ a workshops site (Astro Starlight), one page per exercise, with an optional online editor (StackBlitz)
✅ PDFs of the deck and the workshops
✅ ZIPs: a starter and a solution for each workshop, plus a ready-to-share participant kit

There's no chapter list to maintain: the number at the start of a file name sets its place in the course. You write content, and the build does the rest.

Get started in one command:
`npm create training-kit my-training`

🔗 https://github.com/EmmanuelDemey/training-kit

## Slack (FR)

Hello tout le monde 👋

Petit partage d'un side project qui me tient à cœur : **training-kit** 🎓

Vous connaissez sûrement la galère quand on prépare une formation : les slides d'un côté, les énoncés de TP de l'autre, les PDF à regénérer, les zips starter/solution à refaire à chaque correction de typo… 😅 J'en ai eu marre, alors j'ai automatisé tout ça !

Le principe : vous écrivez du Markdown et du code dans des dossiers numérotés (`01-intro`, `02-composants`…), et l'outil vous sort :
• 🖥️ un deck de slides (Slidev)
• 📚 un site de TP (Astro Starlight), avec un éditeur en ligne StackBlitz en option
• 📄 les PDF des slides et des TP
• 📦 les ZIP : un starter et une solution par TP, et un kit participant prêt à distribuer

Pas de sommaire à maintenir : c'est le numéro au début du nom de fichier qui fixe l'ordre ✨

Pour tester, une seule commande :
`npm create training-kit ma-formation`

👉 https://github.com/EmmanuelDemey/training-kit

Si vous donnez des formations, des cours ou des ateliers internes, ou si le sujet vous parle tout simplement, venez m'en parler en DM ou en thread 🙌 Les retours, les idées et les ⭐ sont aussi les bienvenus 😄
