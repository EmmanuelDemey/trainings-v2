# Going further: `type-challenges`

- [github.com/type-challenges/type-challenges](https://github.com/type-challenges/type-challenges)
- Hundreds of exercises, graded **warm-up → easy → medium → hard → extreme**
- Re-implement `Pick`, `Readonly`, `Awaited`, then parse strings, do arithmetic
  on tuples, write a JSON parser… in types
- Each challenge opens in the TypeScript Playground, with its tests
