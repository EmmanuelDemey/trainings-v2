# Training objectives

- Understand the **core concepts** of JavaScript (variables, equality, conditions, loops)
- Be able to **write and use simple functions**
- Manipulate **arrays** and their most common methods
- Dynamically modify the content of a web page with the **DOM**
- Handle user events with **event-driven programming**
- Build **interactive interfaces** with simple JavaScript scripts

---

# Prerequisites

- Basic understanding of **how the Web works**
- Basic knowledge of **HTML**
- Basic knowledge of **CSS**
- Beginner level in writing **loops and functions**
- Bring your own **laptop**

---

# Target audience

- Web designers and integrators
- Junior developers
- Anyone starting with front-end development

Duration: **3 days**

---

# Teaching methods

- Alternation between **theoretical lectures** and **hands-on practice**
- Workshops and practical exercises
- Field experience feedback from the trainer
- Digital course materials provided
- Continuous evaluation (self-assessment questionnaire, workshops, exercises, final questionnaire)
